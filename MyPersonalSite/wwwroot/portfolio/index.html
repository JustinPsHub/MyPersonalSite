Enterprise analytics spans HR, budget, cyber, procurement, and other domains. Connecting those needs takes dependable data flows, useful application interfaces, and controlled access across the platform.

APPLIED AI

A clearer way to investigate.

C# · Blazor · Azure OpenAI · RAG

Project details +

U.S. Department of the Treasury · Blazor / Azure OpenAI

Challenge

Power BI audit records hold valuable operational context, but investigating activity across millions of events calls for both platform knowledge and specialized queries.

My contribution

I architected and integrated a custom Azure OpenAI solution within the enterprise Blazor portal, using retrieval-augmented generation to connect questions to audit context from the data lake.

GOVERNED ANALYTICS

One model. Shared understanding.

I architected a human-capital semantic model with incremental refresh, partition management, and row-level security.

SSAS Tabular · Power BI · DAX

Project details +

U.S. Department of the Treasury · Human-capital analytics

Challenge

Workforce reporting spans personnel actions, pay, and many related datasets. Teams need consistent measures and access that respects each user’s role.

My contribution

I architected a human-capital tabular model with 25 fact tables and 90 dimensions, including incremental refresh, partition management, and row-level security.

Design choice

Define common measures in the semantic layer and govern access in the model, giving reporting a reusable foundation.

Outcome

A shared semantic foundation spanning 25 fact tables and 90 dimensions. Separately, my wider dashboard work accumulated 500k+ views across 500+ stakeholders; that metric is not attributed solely to this model.
