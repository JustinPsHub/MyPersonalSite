Model assumptions & data definitions

Illustrative sensitivity analysis, not a forecast. Added latency propagates through the directed call graph using fixed synchronous exposure weights: gateway → data 65%; gateway → identity 35%; data → storage 80%; identity → storage 50%. Asynchronous telemetry has zero latency exposure. Portfolio impact is weighted by selected request volumes. Throughput and failure rates stay fixed; queueing, retries, and saturation are not modeled. Metrics count service-level requests, so one user action may contribute to several services. All records and service relationships are synthetic.
